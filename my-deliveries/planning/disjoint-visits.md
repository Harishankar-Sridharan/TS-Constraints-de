# Disjunkte Besuche

Erzwingt eine Rückkehr zum Depot zwischen zwei Besuchswiederholungen.

\
**Format:** Binär

\
Wenn diese Option auf **1** gesetzt ist, erzwingt das System eine Rückkehr zum Depot zwischen zwei aufeinanderfolgenden Wiederholungen desselben Besuchs.

\
Wenn sie auf **0** gesetzt ist, wird die Rückkehr zum Depot nicht erzwungen.

\
**Standardwert:** 0

# Kunden-ID

Dieser Wert ist der Bezeichner des Kunden. Der Bezeichner kann ein interner oder externer Bezeichner sein.&#x20;

\
**Format**: Zeichen

\
**Beispiel:**\
1234

\
Das Zuweisen eines Werts zu dieser Einschränkung ist obligatorisch.\
Es wird empfohlen, dass dieser Wert eindeutig ist.

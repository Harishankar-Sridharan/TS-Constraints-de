# Gelieferte Produkte

Diese Einschränkung legt die Produkttypen fest, auf die eine Ressource zugreifen muss, um an einem bestimmten Standort einen Besuch durchführen zu können.

**Format:** Textliste, wobei jedes Element durch Kommas getrennt ist.

**Beispiel:**\
Wenn eine Ressource an einem Depot anhalten muss, um Gartengeräte zu sammeln, bevor sie einen Besuch abschließt, können Sie **"Garten"** als das erforderliche Produkt angeben.\
Mindestens ein Depot muss dieses Produkt liefern, damit die Ressource den Besuch durchführen kann.

# Maximale Anzahl von Nachladungen/Entladungen

Diese Einschränkung erlaubt es Ihnen, **die Anzahl der Nachladungen pro Tag begrenzen** wenn das Nachladen durch die **Nachladen/Entladen** Einschränkung zulässig ist. Sie definiert die maximale Anzahl von Nachladevorgängen, die eine Ressource an einem einzigen Tag ausführen kann.

**Format:** Nummer

**Beispiel**: SS MM

**Hinweis:** Diese Einschränkung hängt vom **Fahrzeugkapazität**.

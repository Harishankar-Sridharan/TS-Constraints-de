# Gesamtkapazität

Dieser Wert definiert das **Gesamtkapazität, die eine Ressource bewältigen kann** wenn mehrere Mengen für Besuche und Depots beteiligt sind.

**Format:** Numerisch

**Beispiel:**\
Für eine Gemüselieferung hat eine Ressource die folgenden Fahrzeugkapazitäten:

* Fahrzeugkapazität 1: 150 kg (Karotten)
* Fahrzeugkapazität 2: 50 kg (Kürbisse)
* Fahrzeugkapazität 3: 100 kg (Kartoffeln)

Das ergibt insgesamt 300 kg Gemüse. Wenn die **Globale Kapazität** auf 200 gesetzt ist, kann die Ressource **höchstens 200 kg** Gemüse **unabhängig von der Art**.

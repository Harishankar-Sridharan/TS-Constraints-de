# Fahrpausen-Dauer

Diese Einschränkung gibt die Länge der Pause an, die eine Ressource einlegen muss, nachdem sie die maximal zulässige ununterbrochene Fahrzeit erreicht hat, bevor sie ihre Reise fortsetzen kann.

\
**Format**: HH:MM

**Beispiel**:\
Wenn eine Ressource vor der Weiterfahrt eine 45-minütige Pause einlegen muss, sollte die Fahrpause auf _00:45_

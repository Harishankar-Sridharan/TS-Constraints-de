# Maximale Besuche pro Tag

**Dieser Wert legt die maximale Anzahl von Besuchen fest, die eine Ressource an einem einzigen Arbeitstag durchführen darf.**\
Er hilft, die Arbeitsbelastung zu steuern und stellt sicher, dass die Routen überschaubar bleiben.

**Format:** Nummer

**Beispiel:**\
_**Maximale Anzahl von Besuchen** – 12_

# Kosten für Übernachtung

Diese Einschränkung ermöglicht es Ihnen, einen **globalen Kostenbetrag für eine Übernachtung außerhalb festzulegen**. Das System verwendet diesen Wert, um zu entscheiden, ob es kosteneffizienter für die Ressource ist, in einer bezahlten Unterkunft zu übernachten oder zur Basis zurückzukehren. Niedrigere Kosten machen das Übernachten in Bezug auf die Gesamtkosten vorteilhafter.

**Format:** Nummer

**Hinweis:** Diese Einschränkung hängt vom **Maximale aufeinanderfolgende Nächte draußen** Einstellung ab.

**Beispiel:**\
Wenn die Kosten für eine Übernachtung auf **50**, festgelegt sind, wird das System diesen Betrag in die Routenplanung einbeziehen. Die Ressource kann dann an einem Ort übernachten, wenn dies wirtschaftlicher ist als die Rückkehr zur Basis.

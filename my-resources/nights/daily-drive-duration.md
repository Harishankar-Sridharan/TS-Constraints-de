# Tägliche Fahrzeit

Diese Einschränkung ermöglicht es Ihnen, die **maximale gesamte Fahrzeit, die eine Ressource an einem einzigen Tag ohne Übernachtung entfernt von der Basis leisten kann**. Sobald diese kumulierte Fahrzeit erreicht ist, muss die Ressource eine Pause für die in der angegebenen Dauer einlegen **Gesetzliche Nachtruhe-Dauer** Einschränkung angegeben ist.

**Format**: HH:MM

**Beispiel**: Einer Ressource ist es nicht erlaubt, länger als **9 Stunden** an einem Tag zu fahren, ohne eine Nachtruhe einzulegen; daher **Tägliche Fahrzeit = 09:00**.

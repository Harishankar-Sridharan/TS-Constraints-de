# Wöchentliche Arbeitszeit

**Dieser Wert definiert die maximale Anzahl an Arbeitsstunden, die die Ressource jede Woche leisten darf.**\
Die wöchentliche Quote muss vollständig innerhalb der festgelegten Arbeitszeitfenster der Ressource liegen.

**Format:** HH:MM

**Hinweis:**\
Die Definition einer „Woche“ hängt von der Konfiguration ab:

* Wenn die **Gearbeitete Tage** Einschränkung verwendet Kalenderdaten, das System verwendet die **Kalenderwoche**.
* Andernfalls verwendet der Planer eine **7-tägige Periode** als wöchentliche Referenz.

**Beispiel:**\
_**Wöchentliche Arbeitszeit** – 40:00_

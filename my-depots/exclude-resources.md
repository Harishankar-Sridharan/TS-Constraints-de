# Ressourcen ausschließen

Diese Einschränkung erlaubt es Ihnen, **geben Sie an, welche Ressourcen NICHT erlaubt sind, eine Site zu besuchen**. Die eingegebenen Werte müssen **den Namenwerten entsprechen** die jeder Ressource zugewiesen sind.

**Format:** Zeichen, aufgeführt als **durch Kommas getrennte Werte** wenn mehrere Ressourcen angegeben werden.

**Beispiel:**

* Wenn Ressource A und Ressource B **nicht** eine Site besuchen sollen, geben Sie ein: Ressource A, Ressource B

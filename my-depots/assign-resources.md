# Ressourcen zuweisen

Diese Einschränkung erlaubt es Ihnen, **geben Sie an, welche Ressourcen berechtigt sind, eine Website zu besuchen**. Die eingegebenen Werte müssen **den Namenwerten entsprechen** die jeder Ressource zugewiesen sind.

**Format:** Zeichen, aufgeführt als **durch Kommas getrennte Werte** wenn mehrere Ressourcen angegeben werden.

**Beispiel:**

* Wenn nur Ressource A und Ressource B berechtigt sind, eine Website zu besuchen, geben Sie ein: Ressource A, Ressource B
